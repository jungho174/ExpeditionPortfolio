# 적 공격 타이밍 조절

돌 골렘의 2연타·3연타·지연 공격은 `Combat/Patterns/StoneGolem`의 패턴 DA에서 `Hits` 배열로 조절한다. 각 타격의 Notify와 피해·방어 시간, 캐릭터별 반격 연결은 `docs/stone-golem.md`를 참조한다. 아래는 Hits가 빈 기존 단일 공격의 설정이다.

콘텐츠 브라우저에서 `Content/ExpeditionPortfolio/Combat/Patterns/DA_EnemyBasicAttack`을 연다. 코드를 다시 빌드하지 않고 아래 값을 바꿀 수 있다.

| 에디터 프로퍼티 | 기본값 | 의미 |
|---|---:|---|
| Defense Window Duration | 0.6초 | 타격 몇 초 전부터 방어 입력을 받을지 |
| Parry Success Duration | 0.2초 | 타격 직전 몇 초 동안 패링이 성공할지 |
| Hit Time Offset | 0초 | 기준 타격보다 앞당기거나 늦추는 시간. 음수는 빠르게, 양수는 느리게 |
| Telegraph Duration | 1초 | 적 공격 애니메이션을 시작하기 전 대기 시간 |
| Damage | 20 | 패링 실패 또는 미입력으로 받는 피해 |
| Attack Montage | AM_EnemySpellAttack | 적이 재생하는 공격 모션 |

`AM_EnemySpellAttack`은 `Content/ExpeditionPortfolio/Animation/Enemy`에 있다. 원본 `AS_Spell_Cast_Attack`을 보존하고 프로젝트 복사본을 사용한다. 모션은 약 6.8초이며 팔을 앞으로 뻗은 직후인 약 4.7초에 `EnemyHit` Notify를 배치했다. 이 Notify를 이동하면 기준 타격 위치가 바뀐다. 소수점 단위 조정은 Data Asset의 `Hit Time Offset`으로 한다. Notify가 없는 경우에만 고급 설정 `Fallback Hit Time`을 사용한다.

기본 설정에서 모션 시작 후 약 4.1초에 방어 입력이 열리고, 4.5~4.7초에 패링이 성공한다. 회피는 방어 구간 전체에서 성공한다. 너무 이른 패링은 실패로 확정되며 같은 공격에 다시 입력할 수 없다. 타격 이후의 입력도 거부한다. 방어 결과와 피해는 타격 순간 반영하고, 적의 마무리 모션이 끝나야 다음 플레이어 턴이 시작된다. 타격 시 `PARRY`, `DODGE`, `HIT` 표시가 약 1.2초 나타난다.

## PIE에서 반복 조정

1. PIE에서 전투에 들어간 뒤 플레이어 명령 턴을 기다린다.
2. 필요하면 Shift+F1로 마우스를 에디터에 돌려주고 패턴 Data Asset을 연다.
3. 방어/패링 시간이나 보정값을 수정한다.
4. 게임에서 일반 공격을 선택하여 다음 적 공격을 확인한다.
5. 마음에 드는 값을 찾으면 Data Asset을 저장한다.

패턴은 적 턴의 예고가 시작될 때 선택하고 시간과 피해를 복사한다. 이미 선택된 공격은 진행 중 값 변경의 영향을 받지 않는다. 다음 선택부터 변경값을 사용하므로 PIE를 종료할 필요가 없다. 원본 Data Asset을 편집하는 작업이므로 최종적으로 유지할 값을 확인하고 저장한다.

패링 시간은 방어 시간 이하여야 한다. 보정된 타격은 방어 구간 전체를 확보할 수 있어야 하고 모션 종료보다 빨라야 한다. Montage의 Rate Scale은 1을 사용한다. 무효 설정은 Output Log에 원인을 남기고 선택에서 제외하며, 유효한 패턴이 없으면 기본 Timer 공격으로 대체한다.

## 검증할 동작

- 타격 직전 패링 성공, 너무 이른 패링 실패, 회피 성공, 미입력 피격.
- 첫 입력 후 연타 거부와 피해/반격의 1회 적용.
- 타격 이후에도 명령 버튼은 숨겨지고 모션 완료 후 다시 표시.
- PIE 중 값 변경이 진행 중 공격에는 영향을 주지 않고 다음 공격부터 적용.
- 패링 반격 승리와 피격 패배, 모션 중단/Notify 누락에서도 진행이 멈추지 않음.
