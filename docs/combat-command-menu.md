# 전투 명령 메뉴

현재 캐릭터의 평타·기술·반격과 공통 패링 설정은 [캐릭터별 전투 설정](character-actions.md)으로 분리됐다. 아래의 이전 DA 경로 예시보다 새 프로필의 연결을 우선한다.

현재 기술 메뉴는 `단일공격 / 파이어볼 · 피해 25`, `광역공격 / 블리자드 · 피해 30`으로 표시한다. 기술명과 설명 사이에만 줄을 바꾸며 설명의 자동 줄바꿈은 사용하지 않는다. 피해 수치는 각 행동 DA에서 읽으며, 대상 범위·무제한·남은 사용 횟수 문구는 표시하지 않는다. 실제 사용 제한과 소진 시 표시·입력 처리는 유지한다.

게임 UI 글꼴은 상단 `TXT_BattleState`와 기술 메뉴 `TXT_WeakMagic`의 공통 설정인 `/Engine/EngineFonts/Roboto`, Bold를 사용한다. 한글은 이 UFont의 대체 글꼴 설정을 따른다. 명령·아이템·기술 메뉴, 방어 문구, 승리·패배와 결과 파티 행의 TextBlock 31개가 같은 설정임을 조회했다. HP 이름/숫자, QTE도 같은 UFont를 참조하며 크기는 각각 기존 유효 크기인 15/23/16을 사용한다. 머리 위 피해·회복 숫자는 사용자 요청으로 통일 대상에서 제외하고 기존 Libre Caslon Display, Default, 크기 54로 복원했다. C++ 기본 경로도 CoreStyle 폰트 대신 UTextBlock 기본 폰트를 복사해 한글 대체 경로를 맞춘다.

HP 수치는 현재 글꼴의 측정 폭을 기준으로 패널 오른쪽 안쪽 10 UI 단위를 넘지 않도록 필요한 만큼 왼쪽으로 보정한다. 크기는 23을 유지한다. 폰트 통일 실행 검증에서는 기본/아이템/기술 메뉴, HP, 실제 파이어볼 QTE와 피해 숫자, 패배→재도전→승리의 7개 화면과 런타임 폰트 82건을 확인했다. 승패 화면 진입에는 진단용 HP 변경을 사용했다. 사용자 직접 플레이의 최종 글꼴·가독성 확인은 남아 있다.

통일 당시 `ExpeditionPortfolioEditor Win64 Development` 빌드 통과 후 새 프로세스에서 HP·숫자·QTE의 저장된 Roboto Bold 참조와 크기를 재조회했다. 외곽선·자간·재질 등 폰트 이외 스타일 필드의 불필요한 변경은 없었고, 실제 기술 메뉴에서 HP 숫자가 패널 안쪽에 표시되는 것을 확인했다. 이후 머리 위 피해·회복 숫자만 위 예외 글꼴로 복원했다.


플레이어 명령 턴에는 캐릭터 오른쪽에 기울어진 메뉴가 표시된다. HP는 적 머리 위와 우측 하단 아군 패널에 표시한다. 메뉴를 열거나 뒤로 가는 것은 턴을 소비하지 않으며, 확정한 행동이 승인되면 메뉴 전체를 숨긴다. 다음 명령 턴에는 첫 화면으로 돌아온다.

2026-11-18 HP 색상: `UI/DA_CombatHealthHUD`의 Party Health Color와 Enemy Health Color는 sRGB `#C92D2D`를 선형 색 공간으로 변환한 값 `(0.584078, 0.026241, 0.026241, 1)`이다. 이전 `#DC5860`이 분홍빛으로 보인다는 직접 플레이 피드백에 따라 분홍 기운을 줄이고 더 진한 빨강으로 조정했다. HP 길이와 실제 수치 계산은 그대로 유지한다.

더 진한 빨강 적용 후 `ExpeditionPortfolioEditor Win64 Development` 빌드를 통과했고, 저장된 DA 두 색의 선형값을 다시 조회했다. 새 PIE에서 적 두 명과 우측 하단 아군 HP가 진한 빨강으로 표시되는 화면을 확인했다. 기술 목록의 `파이어볼 · 피해 25`와 `블리자드 · 피해 30`도 각각 한 줄로 유지된다. 이번 색상에 대한 사용자 직접 플레이의 최종 확인은 남아 있다.

아군 HP 패널 위 마름모와 사람 실루엣은 `DA_CombatHealthHUD → Party → Show Party Portrait`로 함께 표시 여부를 조절한다. 현재 프로젝트 설정은 끔이다. 이 옵션은 초상화·대체 실루엣·마름모 테두리에만 적용되며 이름과 HP의 배치는 기존 좌표를 사용한다.

장식 숨김 변경 후 `ExpeditionPortfolioEditor Win64 Development` 빌드를 통과했다. 새 에디터에서 DA 저장 성공 로그와 false 설정값을 확인했고, 실제 전투 기술 메뉴 화면에서 마름모·실루엣이 사라지고 이름·HP가 표시되는 것을 확인했다. 사용자 직접 플레이의 최종 화면 확인은 남아 있다.

W/S로 현재 목록의 위/아래 항목을 고르고 Space로 선택한다. 처음 명령 턴은 아이템에 선택이 놓이며 목록 양 끝은 순환한다. 아이템·기술 목록에는 뒤로 버튼도 포함한다. 하위 목록 진입은 첫 사용 가능한 항목, 뒤로 복귀는 원래 상위 메뉴(아이템/기술), 대상 선택 취소는 방금 고른 항목을 유지한다. 수량이 없어 비활성인 물약은 건너뛰지만, 횟수를 소진한 강한 마법은 기존 NoAP 안내를 위해 선택할 수 있다.

W/S로 실제 선택 항목이 바뀔 때마다 `DA_BattleUIAudio → Skill Menu`의 기존 메뉴 사운드(`UI_Skill_NavigatePage`)를 1회 재생한다. 첫 화면·아이템·기술 목록과 뒤로 항목에 공통 적용하며, 선택이 그대로이거나 메뉴 탐색을 거부한 입력에는 재생하지 않는다. 파일·볼륨·Delay·Start Time은 기존 Skill Menu 설정을 사용한다.

이동음 추가 검증: Editor Development 빌드 성공. PIE의 실제 W/S 입력에서 선택 변경마다 위 사운드 생성 로그가 정확히 1회 발생했고, 아이템 목록의 뒤로 항목에서도 확인했다. 기술 목록의 양방향 이동, 방향 0 및 대상 선택 중 이동 거절도 실행 검증했다. 사용자 직접 청음은 남아 있다.

선택 버튼은 원래 Render Scale의 기본 1.12배로 커진다. WBP_CombatHUD → Class Defaults → Combat / Menu → Menu Selection Scale에서 배율을 조절한다. 1이면 확대가 없다. Designer에서 조정한 버튼의 원래 배율·각도는 보존하며 선택이 이동하면 이전 버튼은 원래 크기로 돌아온다. 숫자키와 마우스 클릭도 계속 사용할 수 있다.

Space는 한 번에 현재 단계만 처리한다. 목록에서 기술/평타/물약 선택 → 대상 선택에 진입하고, 다음 새 Space로 대상을 확정한다. 대상 단계의 A/D·Space, QTE와 승리/패배 결과창 조작은 기존 경로를 사용한다. 결과창에는 W/S 이동이나 선택 확대를 추가하지 않는다. 탐험에서는 W/S 이동 입력을 소비하지 않으며 숨긴 메뉴·확정 대기·공격·방어 중에는 명령 메뉴 탐색을 거부한다.

2026-11-08 검증: Editor Win64 Development 빌드와 전투 자동화 테스트 53개가 통과했다. 실제 PIE에서 S/Space로 선택 확대·기술 목록 진입·대상 선택까지 단계별 진행을 확인했다. 실행 중 목록 순환, 뒤로 복귀, 물약/평타 대상 선택 및 취소, 다음 턴 초기화, 소진 기술 거절, 결과 상태의 명령 차단도 확인했다. 패배 결과창에서는 실제 W/S 입력으로 선택·크기가 변하지 않았으며 탐험 W 이동도 유지됐다. 확대 크기와 조작감에 대한 사용자의 최종 플레이 확인은 남아 있다.

| 화면 | 입력 | 동작 |
|---|---|---|
| 첫 화면 | 1 / 아이템 클릭 | 아이템 목록 |
| 첫 화면 | 2 / 기술 클릭 | 약한 마법·강한 마법 목록 |
| 첫 화면 | 3 / 공격 클릭 | 적에게 접근하여 맨손 공격 후 복귀 |
| 아이템 | 1 / 물약 클릭 | 아군 대상 선택 → Space 확정 → HP 회복, 물약 1개와 턴 소비 |
| 기술 | 1 / 약한 마법 클릭 | SpellAttack / 불꽃 발사체 → 적 위치 폭발 |
| 기술 | 2 / 강한 마법 클릭 | 기존 준비 모션 / IceMist, 전투당 1회 |
| 하위 메뉴 | Backspace / 뒤로 클릭 | 첫 화면으로 복귀 |

패링 E, 회피 Q는 기존 방어 창에서 사용한다. 물약은 생존 아군이 없거나 남은 수량 0에서 선택할 수 없다. 풀피에서도 효과 없이 사용할 수 있으며 물약 1개와 턴은 동일하게 소비한다. 현재 물약은 회복 VFX와 대기 구간을 사용하며 병을 들고 마시는 전용 애니메이션은 없다. 기술과 일반 평타 모두 적 대상 선택을 거친다. 적·아군 대상은 A/D로 이동하고 Space로 확정하며, 좌클릭은 대상을 확정하지 않는다. 메뉴·거절·턴 사운드 설정은 docs/combat-sounds.md의 DA_BattleUIAudio를 참조한다.

## 에디터에서 조절

평타 접근·복귀는 현재 AM_Dash 기반 도약·백대시로 변경했다. 접근 0.32초/복귀 0.30초, 추가 높이 30cm/18cm로 최초 연결하며 상세 설정과 검증은 `docs/melee-dash.md`를 참조한다.

- `Content/ExpeditionPortfolio/Combat/Rules/DA_BattleRules`: 턴 대기와 전투당 파티 공용 아이템 수량을 설정한다. 물약 회복량·VFX·사운드는 `Combat/Items/DA_HealingPotion`, 사용 동작·타이밍은 `Characters/PlayerMage/Combat/DA_PlayerMageItemUse`다. 새 전투에서 초기 수량을 지급하며 영구 인벤토리는 아니다.
- `Content/ExpeditionPortfolio/Characters/PlayerMage/Combat/DA_PlayerMageBasicAttack`: 현재 평타 피해·접근/복귀 시간·거리·타격 시간·몽타주·사운드를 조절한다. 타격 시간은 공격 Montage 시작 기준이다.
- `WBP_CombatHUD`의 Designer: `CN_CommandMenu`의 Render Transform Angle 기본 -8도. `CN_MainMenu`, `CN_ItemMenu`, `CN_SkillMenu` 아래 버튼의 위치·크기·스타일을 편집한다. 하위 메뉴는 Designer에서 Visibility를 임시 Visible로 바꾸어 확인한 뒤 기본 Collapsed로 저장한다.
- `Characters/PlayerMage/Combat/DA_PlayerMageVisual → Menu Screen Offset`: 캐릭터 투영 좌표에서의 메뉴 위치 보정. 현재 (90, -50)으로 몸통 오른쪽에 배치한다. 실행 중에는 Canvas 위치를 다시 계산하므로 위치 보정은 이 프로퍼티를 사용한다. 하단 제한은 현재 보이는 페이지의 버튼·제목·뒤로 버튼 높이에 여백 20을 더해 계산한다. 짧은 첫 메뉴에 기술 목록의 빈 높이를 예약하지 않는다.

배치는 Blueprint에 저장하며 C++는 페이지 전환, 명령 전달, 상태별 표시와 화면 좌표 추적을 담당한다. 호흡 모션과 카메라에 부드럽게 맞추기 위해 명령 메뉴 표시 중에는 NativeTick에서 매 프레임 투영한다. 숨김 또는 다른 전투 상태에서는 추적 계산을 하지 않는다. HP나 피해·물약 수량을 위젯에 원본 데이터로 보관하지 않는다.

## 호흡 모션과 추후 카메라 연출 연결

메뉴 기본 위치는 현재 카메라에서 플레이어의 위치를 투영해 계산한다. 여기에 `spine_03`의 실제 애니메이션 이동과 pelvis→몸통 방향의 변화를 제한·보간하여 더한다. 기준 자세는 명령 턴의 첫 갱신에서 액터 로컬 좌표로 저장하며 매번 현재 카메라로 다시 투영한다. 카메라 이동을 몸의 호흡으로 오인하거나 이전 화면 좌표를 계속 따라가는 방식이 아니다. 기존 Designer의 기본 기울기는 유지하고 모든 하위 메뉴가 같은 미세 움직임을 사용한다. HP는 움직이지 않는다.

`WBP_CombatHUD` Class Defaults → Combat / Menu Motion:

| 프로퍼티 | 기본값 | 의미 |
|---|---|---|
| Visual Data의 Menu Motion Bone / Menu Reference Bone | spine_03 / pelvis | 캐릭터별 호흡 기준 뼈. WBP가 아닌 해당 캐릭터의 Visual Data에서 조절 |
| Menu Sway Strength | 1.2 | WBP_CombatHUD의 현재 설정. 화면상 몸통 이동 반영 배율 |
| Menu Max Sway | 3 | 최대 이동 거리, DPI 적용 전 UI 단위 |
| Menu Max Sway Angle | 0도 | 추가 회전은 기본 비활성. Designer의 기울기는 유지 |
| Menu Motion Follow Speed | 2.5 | 약 0.4초의 완화 시간으로 빠른 변화를 줄임 |

잔떨림 완화 후 이동이 너무 약하다는 직접 플레이 피드백에 따라 WBP_CombatHUD의 이동 강도를 0.5에서 1.2로 올렸다. 추가 회전 0, 최대 이동 3, 추적 속도 2.5와 픽셀 스냅 비활성화는 유지한다. C++ 기반 클래스의 초기 강도는 0.5이며 게임에서 사용하는 Blueprint가 1.2로 덮어쓴다. 카메라의 기본 위치 투영에는 이 호흡 보간을 적용하지 않는다.

시점 대상 교체, 급격한 카메라 이동/회전/FOV 변경, 화면 크기 변경과 메뉴 재표시에서는 기준과 보간 잔여값을 초기화한다. 부드러운 카메라 이동에서는 기본 위치가 현재 카메라를 그대로 따르고 호흡 성분만 보간한다. 캐릭터가 카메라 뒤에 있어 투영에 실패하면 메뉴를 투명·입력 불가로 두며 다시 보이면 복원한다. 뼈가 없는 캐릭터는 고정된 기본 위치로 표시한다.

추후 카메라 연출 제어에서는 `Set Command Menu Presentation Enabled(false)`로 전환 중 메뉴를 숨기고, 구도 전환 완료 후 true로 표시한다. 이 게이트는 명령 턴에서도 메뉴 단축키 선택을 막지만 전투 상태·턴·방어 입력을 바꾸지 않는다. 명시적인 컷 지점에는 `Reset Command Menu Motion`도 호출할 수 있다. 카메라의 특정 액터나 숄더뷰 각도에는 의존하지 않는다.

스킬 확정 후 준비 모션·정면 카메라·게이지 타이밍 입력은 후속 행동 연출/판정 시스템에서 진행하고 명령 메뉴는 기존처럼 PlayerAction에서 숨긴다. 게이지 위젯과 그 입력은 명령 메뉴와 별도로 연결한다. 이번 변경에 전투 카메라 시퀀스나 리듬게임 판정은 포함하지 않는다.

근접 연출은 루트 이동을 잠근 프로젝트 복사본 `MM_Attack_01`과 전진/후진 Jog Montage를 사용한다. Actor/캡슐과 카메라는 유지하고 메시만 이동한다. 정상 복귀·중단·전투 정리·EndPlay에서 원래 메시 Transform을 복원한다. 타격 Timer와 행동 ID로 중복 피해를 막고 전체 길이+1초의 안전 Timer로 멈춤을 방지한다. 장애물 경로 탐색을 하는 실제 이동은 아니다.

`Tools/SetupCombatCommandMenu.py`는 기존 HUD 그래프와 튜닝 수치를 보존하며 새 레이아웃이 없을 때만 추가한다. C++ 편집기 API의 `OnVariableAdded`로 GUID를 등록하여 UMG 편집기에서 추가 편집할 수 있게 한다. 기존 `BDR_CommandPanel` / `HB_CommandButtons`는 이전 Blueprint 참조 보존용으로 남겨두고 실행 시 숨긴다.

## 기울어진 버튼 외곽선

`Content/ExpeditionPortfolio/UI/Materials/M_CommandPanelAA`는 명령 버튼 전용 User Interface / Translucent 머티리얼이다. UV의 화면 미분값(`fwidth`)으로 화면 픽셀 기준 경계 폭을 계산하고 가장자리의 불투명도를 부드럽게 줄인다. 지오메트리 경계는 투명하게 두어 회전된 사각형의 딱딱한 경계가 드러나지 않게 한다. 내부 색상과 불투명도는 기존 버튼 Tint를 사용하며 일반/마우스 올림/눌림/비활성 상태에 모두 적용한다. 글자는 별도로 유지하므로 메뉴 전체를 흐리게 만드는 방식이 아니다.

머티리얼의 `FeatherPixels` 기본값은 1.0이다. 값을 올리면 외곽선이 더 부드러워지며 너무 높이면 흐릿해진다. 기본 위치·기울기·호흡 설정과 클릭 영역은 유지한다. 실제 픽셀 격자에서 대각선을 표시하므로 확대 캡처의 계단이 완전히 없어짐을 의미하지는 않는다.

`Tools/SetupCombatMenuBackground.py`는 PIE 밖에서 머티리얼 생성/컴파일과 기존 7개 버튼의 4개 시각 상태 연결을 수행한다. 기존 텍스트·레이아웃·색상·모션 수치는 보존한다. `SetupCombatCommandMenu.py`에서도 마지막 단계에 실행해 새 레이아웃에 동일한 배경을 적용한다.

## 직접 플레이 확인

새 PIE에서 조우 후 1/2로 목록 열기, 뒤로, 마우스 선택을 확인한다. HP가 꽉 차도 물약을 선택·사용할 수 있어야 한다. 풀피 사용은 HP를 유지하고 수량과 턴만 소비하며, 피해 후 사용은 HP와 수량이 한 번만 바뀌어야 한다. 행동과 적 턴에는 명령이 숨고 HP는 남는다. 일반 공격은 마법 효과 없이 접근·타격·복귀하고 기술 목록의 두 마법은 기존 연출로 실행되어야 한다. 강한 마법 사용 후 비활성 표시, 다음 턴 첫 화면 복귀와 승리 후 HUD 숨김을 확인한다. 회복·근접 타격의 느낌과 메뉴 위치의 최종 평가는 사용자의 직접 플레이로 확인한다.
